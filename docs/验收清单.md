# 明早验收 · 演示脚本

> 目标：3 分钟内把「今天要学什么 → 学一个词 → 桌面直接复习 → 看数据」跑通。

## 0. 准备

```powershell
# 装到模拟器 / 手机
adb install -r app\build\outputs\apk\debug\app-debug.apk
```

首次启动会导入 120 个词，等 1~2 秒。

## 1. 首页（30 秒）

- 指出「今日待学 10 词」和进度环；
- 说明：新词和到期复习一起排进今日任务，复习优先。

## 2. 卡片学习（60 秒）

- 点「开始今日学习」；
- 先不翻面，点「认识」→ 说明这一次是「凭记忆判断」；
- 下一个词点卡片翻面 → 看到释义、例句、记忆等级；
- 点「听发音」；
- 点「忘了」；
- 打开「我的 → 演示加速」再学一个词，回到卡片可以看到「下次复习 2 分钟后」——
  **这是算法真实生效的证据**。

## 2.5 拼写听写（40 秒）

- 首页 →「✍ 拼写听写」；
- 说明：听发音，写单词，写对升一级，写错直接回到第一批；
- 故意写错一个，展示红色反馈和正确拼写；
- 强调这不是小游戏，**判分结果会写回复习计划**。

## 3. 桌面小组件（60 秒）

- 返回首页 → 点「添加 / 预览」，把 4×3 小组件钉到桌面；
- 直接点小组件上的「认识 / 忘了」→ 词立刻换下一个，**没有打开 App**；
- 说明实现：`PendingIntent` → 广播 → `goAsync()` 协程写 Room → `AppWidgetManager` 局部刷新；
- 再演示 2×2 迷你版。

> **如果桌面没有组件选择器（如雷电自带 Launcher3）**：
> 点「预览」进入小组件预览页，那里用的是同一份 `widget_word.xml`，交互和数据落库完全一致。
> 幻灯片里可以放一张 Pixel 启动器上的真机截图（`docs/` 里已有实测截图）。

## 4. 统计与词库（30 秒）

- 统计页：7 日柱状图、正确率、连续打卡、易忘词数量；
- 词库页：切换三本词书、搜索一个词、切到「生词本」看刚才点「忘了」的词。

## 5. 可能被问到的问题

| 问题 | 回答要点 |
| --- | --- |
| 小组件为什么不走 Activity？ | 走 Activity 会有启动动画、打断桌面操作；广播 + `goAsync()` 在后台完成写入，200ms 内刷新。 |
| 复习间隔怎么来的？ | 简化 Leitner：三档反馈映射到 1~7 级记忆盒，间隔 1/2/4/7/15/30/60 天。 |
| 数据存在哪？ | Room（SQLite），三张表；设置存 SharedPreferences；全程离线。 |
| 不同手机小组件不刷新怎么办？ | 已有 `DATE_CHANGED` / `BOOT_COMPLETED` / 每日 WorkManager 三重兜底，并提供手动刷新按钮。 |
| 词库多少词？ | 当前 120 词示例库，结构上支持继续扩充 / 后续做 CSV 导入。 |
